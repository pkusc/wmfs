# ADR-0016 无法满足的放置声明：创建成功 + 可见降级（而不是拒绝）

- 状态：accepted（人类于 2026-10-20 批准）
- 日期：2026-10-20
- 偏离条款：原则 7"宁可拒绝操作，不可……静默降级"与原则 4"单节点能跑"、第 7 章"默认冗余：`/home` 类 replicas=3"之间的取舍
- 是否触及契约层：否（产品决定）
- 批准类别：**需人类决定**（A 栏）；确认批次 1（M4 开工前：M4 创建文件时就会生成短链）
- 相关章节：design.md 3.1.5、3.3.6（`ClusterMap.warnings`）、3.4.2.1、3.4.3、3.8、4.6；semantics.md 第 7 节

## 背景

`wmfs init` 默认给 `/home` 设 `replicas=3`，default 存储类也是 3 副本。单节点集群只有一个故障域，无法满足。同样，`stripe=N` 而可用的不同链少于 N 条时也无法满足。若严格拒绝，单节点集群开箱就用不了 `/home`；若默默少存，就是静默降级。init 直接写入的声明从不经过 `wmfs set`，所以只靠 set 时的警告是不够的。

## 决定（推荐）

1. 创建照常成功：副本不够 → 链以较短长度创建（期望长度仍为声明值）；链不够 → 用 k = min(stripe, 可用链数) 条链创建。
2. **不静默**，警告出现在所有人会看的地方：`wmfs init` 的输出；server 启动日志（leader 就绪时、以及警告变化时）；`wmfs mount` 的输出；`wmfs status` 的第一行；`wmfs get` 的 semantics 行显示"replicas:声明3/实际1"；`wmfs set` 的回复；dashboard 与告警规则。`wmfs status` 统计"副本不足"与"条带数不足"的文件数与字节数。
3. 节点加入后，链管理器自动给短链追加成员（Syncing → Serving），副本差距自动归零（条带数不足的已有文件不迁移，只影响新文件）。
4. `minimal` profile 把 default 类设为 replica=1，单节点演示不出现警告。

## 备选方案

- **拒绝**：`replicas > 故障域数` 或 `stripe > 可用链数` 时 create 返回 `ENOSPC`。最严格，但单节点开箱即不可用。
- **可选的严格模式**：新增目录属性 `placement_strict=true`，设置了的子树按"拒绝"处理。多一个属性，首发不做；你若要，可加入。

## 后果

"声明 vs 实际"模型本来就要求系统回答"差距在哪"，这里的降级是**可见的**；但用户需要留意警告与 status。
