# ADR-0024 CRAQ 链式复制：成员状态、版本、incarnation、前滚与重同步

- 状态：accepted（人类于 2026-10-20 批准）
- 日期：2026-10-20
- 性质：契约层首次定义（理念文档第 3 章"复制、成员、选举、fencing"中的数据链式复制；第 7 章 [默认]"固定大小 chunk + 链式复制（CRAQ）"；参考 DeepSeek 3FS）
- 是否触及契约层：**是**
- 批准类别：**需批准**；确认批次 0（B 栏：技术契约。M4 就生成链、M5 就分配 chunk 版本，所以必须在 M0 前确认）
- 相关章节：design.md 3.4.2、3.4.5

## 背景

评审在早期草稿里找到多处会静默损坏数据的缺陷：头节点快速重启后用同一版本号写入不同内容被后继"按版本相等"吞掉；截断删除 chunk 文件后版本号从头开始与旧副本碰撞；读尾失效时新读尾返回旧版本；同步源取直接前驱（它可能也在同步）；整链重启无规则；"降级为 Syncing 时没有移到末尾"破坏读正确性论证。

## 决定

1. 链 = 有序成员（Serving | Syncing）+ `ver` + `incarnation` + `last_serving` + 最近移除列表。**I0：Syncing 成员总在 Serving 之后**（追加、降级都放到末尾）。head = 第一个 Serving，L = 最后一个 Serving，tail = 最后一个成员。
2. **链生成** `gen_chains(class, replicas)` 在 create 或截断到 0 的执行器闭包里调用，只写 CHAIN 记录，**返回新建链的 `ChainView` 列表**（它们不在批次开始时的集群图快照里，placement 用"快照里的同类链 + 返回值"作为候选），调用后本批结束。故障域不够时链以较短长度创建；可用的不同链少于 `stripe` 时用 k 条链创建（ADR-0016）。
3. head 串行化每个 chunk（同一时刻最多一个 pending 版本，其余写排队 ≤ 8 个）；版本 `V = max(committed + 1, incarnation << 40)`；写本地 pending → 转发给后继（**不占线程**，`call_cb` + pending 表）→ 尾部先提交 → 逆向确认 → 全部成员（含 Syncing）提交后才回复写者。
4. 后继按状态表处理转发（重复确认、增量应用、缺基础版本 → Syncing 回 NEED_FULL / Serving 回 INTERNAL、完整转发整份替换）。
5. 读：有 pending 且不是 L 的成员把读重定向给 L；L 是对外可见的线性化点。Corrupt 的 chunk 一律拒绝读（ADR-0021）。
6. 链变化时先前滚再切换视图：被移出/降级 → 放弃 pending；成为新 L 且旧 L 被移除 → 立即本地提交 pending；成为 tail → 提交并确认；后继变了 → 完整重发。pending 一律前滚、从不回滚；3 s 未确认由 chain-timer 重新驱动。
7. **任何重启都以 Syncing 回链**（由每进程随机的 boot_id 识别）并移到末尾；例外是"唯一幸存者"（没有别的存活 Serving 成员、last_serving 回归、整链重启、管理员 force-serving）：它保持 Serving，**incarnation 加一**，其余降为 Syncing。整链重启时选按链序最后一个原 Serving 成员（已提交版本最全）。
8. 重同步由 Syncing 成员主动向 **L** 拉取（ListChunks + FetchChunk；源端打开的已提交文件是天然快照），同步期间收到过转发的 chunk 不被覆盖；只有紧跟最后一个 Serving 的 Syncing 成员才能被提升。
9. 截断写新版本、从不删文件；只有废弃的 `(ino, epoch)` 才整体删除（DeleteEpoch 沿链传播，离线成员由孤儿扫描清理）。
10. 成员租约：target 0.8 × 8 s 自我隔离，leader 8 s 后移除；链管理器的全部决定都是执行器里独占批次的内部操作。

## 备选方案

- 每 chunk 组一个 Raft（理念文档列出的备选）：更重，小集群不划算。
- 阻塞转发 + 60 s 超时：链上节点互相占满线程时会卡住。否决。
- 从尾节点拷贝整 chunk 回滚：尾节点是 Syncing 时会丢掉已确认的数据。否决。

## 后果

规则较多，但每条都有单元测试、fail point 与不变式检查器（design.md 9.1、9.3）；链的最后一个 Serving 副本离线时该链不可用（诚实：不拿可能过期的副本顶替）。
